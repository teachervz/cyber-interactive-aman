# العرض التفاعلي التزامني

| الملف | لمن؟ |
|---|---|
| `index.html` ، `lesson2.html` | شاشة المعلمة (السبورة) |
| `student.html` | آيباد الطالبة |
| `live.js` ، `live.css` | المزامنة (لا تحتاج تعديل) |
| `firebase-config.js` | إعدادات قاعدة البيانات |

## الإعداد مرة واحدة (Firebase Console)

1. **Authentication ← Sign-in method ← Anonymous ← Enable** (ضروري للمعلمة والطالبات).
2. **Realtime Database ← Rules**: القواعد الحالية تعمل كما هي.
3. **إضافة معلمة**: Realtime Database ← Data ← أضيفي:
   ```
   teachers
     101
       name: "أ. رحاب"
       pin:  "1234"
   ```
   `101` هو رمز المعلمة، وهو نفسه **رمز الفصل** الذي تكتبه الطالبات.
4. **ارفعي المجلد على استضافة** (GitHub Pages أو Firebase Hosting) حتى تفتح الطالبات `student.html` من الآيباد.
   يظهر رمز QR ورمز الفصل في شريحة العنوان.

## أثناء الحصة

- **الدخول**: عند فتح العرض تكتب المعلمة رمزها ورقمها السري (مرة واحدة على الجهاز).
- **👩‍🎓 الطالبات**: كتابة الأسماء (اسم في كل سطر)، والتحضير، وتعديل النقاط يدويًا.
  التحضير تلقائي عندما تدخل الطالبة من الآيباد.
- **🎲 قرعة الأسماء** (أو حرف ق): تختار اسمًا عشوائيًا، ويظهر للطالبة على الآيباد «وقع الاختيار عليكِ».
- **شرائح الأسئلة** (اختيار من متعدد، صح وخطأ، تصنيف، ترتيب، مطابقة): يظهر السؤال في كل آيباد.
  عدد المجيبات يظهر أسفل الشاشة، وعند الضغط على **📣 كشف الإجابة** تُحسب النقاط وترى كل طالبة نتيجتها.
- **العصف الذهني**: أفكار الطالبات تظهر فقاعاتٍ على الشاشة.
- **التعلم التعاوني**: زر 🎲 يوزّع الحاضرات على المجموعات عشوائيًا، وترى كل طالبة مجموعتها ومهمتها.
- **لوحة الصدارة**: أعلى 8 طالبات.
- **↺ حصة جديدة**: تمسح الإجابات والنقاط (تبقى الأسماء والتحضير). تبدأ حصة جديدة تلقائيًا عند تغيير الدرس أو اليوم.

بدون إنترنت أو بدون دخول المعلمة يعمل العرض كالسابق، لكن بدون الطالبات.
